
# Maison de Beauté

## Description
Maison de Beauté est une application web développée avec HTML,
Bootstrap, JavaScript et JSON. Elle permet d'afficher et de gérer
des clientes, des produits cosmétiques et leurs commandes.

## Structure du projet
- index.html : page principale
- css/style.css : styles de l'application
- data/customers.json : données des clientes
- data/products.json : données des produits
- data/orders.json : données des commandes
- js/state.js : état central
- js/dataService.js : chargement des fichiers JSON
- js/selectors.js : recherche, relations et calculs
- js/view.js : affichage dynamique
- js/app.js : initialisation et événements

## Fonctionnalités
- Recherche par nom de cliente
- Filtrage par statut et catégorie
- Calcul des montants des commandes
- Affichage des détails d'une commande
- Gestion des erreurs de chargement

## Lancement
1. Ouvrir le dossier dans Visual Studio Code.
2. Installer l'extension Live Server.
3. Cliquer avec le bouton droit sur index.html.
4. Choisir Open with Live Server.
